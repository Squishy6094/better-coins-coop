# Better Coins
 Overhauls the coin collecting expirience to make 100 coins stars fun and satisfying to work towards

## Vanilla Modifications / Quality of Life

While the main attraction is how coins are signicantly easier to collect, a lot of things have been changed to improve the coins collecting expireince!

While a lot is changed, one of the main goals is to not make everything feel vanilla and prevent detrimental interactions. 

### Behavior Modifications
A majority of object behaviors have been modified to either:
- Allow using completed objectives as a means for coins
- Give non-rewarding enemies coins
- Remove inconsistencies and niche mechanics
- Ensure that you're rewarded for 'winning' an interaction

## Master Cap Challenge
After collecting all the stars, you're able to run the Master Cap Challenge!

An arcade mini-mode with the goal to collect as many coins as you can while your cap still lasts, putting your knowlage of new and existing mechanics to the test!
